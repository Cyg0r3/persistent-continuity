# System Principles

> Optional. Operating principles that guide design/behaviour choices on this project.
> Loaded on every resume. Delete this file if you don't need it.

## P1: Deterministic over clever
Prefer predictable, reproducible behaviour. Same inputs → same outputs is recoverable.

## P2: Explicit state over hidden state
If it matters, it is written to the event log. Nothing important lives only in chat.

## P3: Recoverability over compression
When forced to choose, preserve the ability to rebuild over saving space.
